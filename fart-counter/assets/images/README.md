# Assets - Imágenes

Este directorio contiene las imágenes de la aplicación.

## Archivos necesarios:

### fart-icon.svg
- Icono principal (💨 como SVG)
- Tamaño: 64x64px
- Usado en el botón principal y header

### logo.svg
- Logo del proyecto
- Tamaño: 200x100px
- Usado en el header

### reset-icon.svg
- Icono para el botón reset
- Tamaño: 32x32px
- Usado en botones

## Instrucciones:
1. Crea estos archivos en SVG o importa PNGs
2. Asegúrate de que las rutas coincidan con los referencias en index.html
3. Para SVG inline (recomendado para rendimiento), copia el código SVG directamente en el HTML

## Alternativa: Usar solo emojis
La app actualmente usa emojis, que funcionan sin necesidad de archivos adicionales:
- 💨 para pedo
- 💩 para el contador
- etc.

Si deseas agregar imágenes, reemplaza los emojis con etiquetas `<img>`.
